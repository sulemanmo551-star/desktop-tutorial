# GTMDJD Verified Comparison Portal

Browser-based drag-and-drop reconciliation for MyCases exports and GTMDJD paid table-of-content files.

## Capabilities
- XLS/XLSX/CSV/ZIP input
- PDF and image OCR
- Duplicate-file detection
- Duplicate-payment deduplication
- Strict matching
- Unique MyCases payment enforcement
- Consolidated exception queue
- Boss-ready workbook and ZIP export

## Privacy
All processing happens in the browser. Original files are never modified. The app does not email anyone, write to Airtable, or upload source files to a server.

## Verification boundary
Poor-quality scans may still require human review. Ambiguous results are classified as Needs Review or Not Matched rather than silently accepted.
